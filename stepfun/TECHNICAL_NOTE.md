# Local Notes · 一页技术说明

**实现**：浏览器 Web Worker 运行 Transformers.js **4.3.2** / ONNX Runtime Web；文档和查询均为本地推理。模型 [Xenova/all-MiniLM-L6-v2](https://huggingface.co/Xenova/all-MiniLM-L6-v2/tree/751bff37182d3f1213fa05d7196b954e230abad9)，Apache-2.0，revision `751bff37182d3f1213fa05d7196b954e230abad9`，384 维、mean pooling、L2 normalization、最长 256 tokens。使用该公开发布的 INT8 动态量化及 FP16 ONNX 导出，不声称自行训练或重新量化。

**体积**：按相同口径计算单种 ONNX 权重 + 4 个共享 tokenizer/config 文件，不含 JS/WASM 运行时。FP32 **91,100,408 B**，INT8 **23,685,172 B**，FP16 **46,010,627 B**；压缩比分别 **3.846× / 1.980×**。原始权重分别为 90,387,606 / 22,972,370 / 45,297,825 B。文件哈希与下载计时见 `results/model-manifest.json`；本机顺序下载三种完整产物合计 **16.62 s**，公网传输时间取决于网络。

**后端**：显式尝试 `device: 'webgpu', dtype: 'fp16'`；无适配器、无 `shader-f16` 或初始化失败时自动使用 `device: 'wasm', dtype: 'q8'`，界面显示实际后端与降级原因。WASM 最多 4 线程；COOP/COEP 开启，推理在 Worker 中执行。模型按精度缓存并复用已加载 session；切换时释放旧模型。

**数据库**：seekdb-js **1.4.0** 创建 384 维 cosine/HNSW 集合和 IK smart 全文索引，存原文、ID、向量、标题及模型元数据；一条参数化 SQL 在 seekdb 内计算全文前 50、精确 cosine 前 50 和 RRF（常数 60），Node 和浏览器均不拼合候选。每批最多 64 条 upsert 后刷新索引。内容哈希稳定 ID 支持增量与重复导入；集合隔离、localStorage 选择状态和过期响应保护保证切换正确。

**实测条件**：2026-11-10，Apple M4 / 24 GiB，macOS arm64，Chromium **157.0.0.0** 内嵌浏览器，硬件并发 10，WASM 4 线程；本地 Release seekdb **1.4.0.0**、SQL 端口 12016，24 篇固定工程知识文档、12 个手工标注问题，K=5，每组重复 3 轮。下表为预热后的中位数；查询指标覆盖每组 36 次查询。`results/browser-1794306350102-32b0c353.json` 保存全部结果、相关性标签、分阶段时间及未汇总的数据。

**结论与范围**：同后端、同 batch 下 INT8 文档推理减少 **26.47%**；固定 INT8 下 batch 4 再减少 **36.94%**，相比 FP32 基线合计减少 **53.63%**。WebGPU 批处理相比 FP32 基线减少 **81.88%**，但短查询端到端较慢。四组精确向量检索的 Recall@5 也均为 **0.958**，nDCG@5 均为 **0.901**，该评测集未见量化质量下降。数据库时间差异含缓存/写入顺序影响，不归因于模型量化。首次模型加载（已下载至本机，包含本地获取与 session 初始化）为 FP32/WASM **817.54 ms**、INT8/WASM **246.75 ms**、FP16/WebGPU **359.83 ms**；第二个 INT8 配置复用 session。不能将这些视为公网冷启动时间。

**验收与局限**：真实 WebGPU、真实 WASM 全流程、数据库增量与隔离测试通过。自动降级分支用明确标注的“模拟无适配器”诊断验证，未冒充另一台无 GPU 机器。模型主要适用于英文，当前小型工程语料不代表开放领域中文效果；精确向量查询不代表大规模 ANN 性能。Docker 启动配置已提供，本机实测为本地二进制方式。复现方法见 `README.md`。
